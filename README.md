## 📌 **Resumo do Projeto**

O **NetworkUP** é uma plataforma web desenvolvida e inspirada no tema:

**“O Futuro do Trabalho – Conectando pessoas, competências e propósito por meio da tecnologia.”**

O projeto consiste na criação de uma **rede profissional semelhante ao LinkedIn**, construída com:

- **React**
- **HTML**
- **TailwindCSS**
- **JSON Local**
- **SPA (Single Page Application)**

O objetivo é apresentar uma solução moderna e responsiva que:

🔹 Conecta profissionais  
🔹 Exibe perfis completos e detalhados  
🔹 Estimula networking, colaboração e desenvolvimento de competências  
🔹 Incorpora funcionalidades reais como busca, filtros e interação  

---

## 🚀 **Funcionalidades da Aplicação**

A plataforma inclui:

### ✔️ **Listagem de Profissionais**  
Exibe cards com:
- Foto  
- Nome  
- Cargo  
- Principais Skills  

### ✔️ **Modal Interativo (ao clicar no card)**  
Inclui informações detalhadas como:
- Informações pessoais  
- Formação acadêmica  
- Experiências profissionais  
- Habilidades técnicas e soft skills  
- Hobbies, interesses e idiomas  

Além de dois botões funcionais:
- **Recomendar profissional**  
- **Enviar mensagem**

### ✔️ **Sistema de Busca e Filtros**
Permite encontrar profissionais por:
- Área  
- Cidade  
- Tecnologia  
- Nome  

### ✔️ **Responsividade Completa**
Interface adaptada para:
- Desktop  
- Tablets  
- Mobile  

### ✔️ **Dark Mode**
O sistema oferece suporte total a tema escuro.

### ✔️ **Integração com JSON Local**
Contém **60+ perfis simulados.**


# ▶️ Como Abrir e Executar o Projeto

Siga os passos abaixo para abrir o projeto **GS_FRONT_WEB** no seu computador:

---

### **1️⃣ Faça o download ou clone do projeto**

Se você recebeu o projeto em `.zip`:

1. Baixe o arquivo  
2. Extraia o conteúdo em uma pasta de sua preferência  

Se estiver usando Git:

git clone https://github.com/schiavi18/GS_FRONT_WEB.git

---

### **2️⃣ Abra o projeto no VS Code**

1. Abra o **Visual Studio Code**  
2. Vá em:  
   **File → Open Folder**  
3. Selecione a pasta:  
GS_FRONT_WEB
--- 

### **3️⃣ Instale as dependências**

No terminal do VS Code, execute:

npm install

-> Isso instalará todas as bibliotecas usadas pelo projeto, incluindo:

- React  
- Vite  
- Tailwind CSS  

---

### **4️⃣ Rode o projeto em ambiente de desenvolvimento**

Execute:

npm run dev

bash
Copiar código

O terminal mostrará um endereço local semelhante a:

http://localhost:5173/


👉 **Clique no link ou cole no navegador** para abrir a aplicação.

---

### **5️⃣ (Opcional) Gerar a versão de produção**

Se quiser gerar os arquivos otimizados:

npm run build

Os arquivos finais ficarão na pasta:

/dist
---

### ✔️ Pronto!  
A aplicação estará funcionando localmente no seu navegador.  
Qualquer alteração nos arquivos recarregará automaticamente.
